PARIII (BAKUUU) Birthday Website

PREVIEW:
Open index.html in Chrome. Keep the assets folder beside index.html.

PUBLISH FREE WITH GITHUB PAGES:
1. Sign in at https://github.com/ and create a PUBLIC repository named pariii-birthday.
2. Extract this ZIP on a computer, or upload all files/folders from inside it to the repository root. Important: upload index.html AND the assets folder, not just index.html.
3. In the repository, open Settings -> Pages.
4. Under Build and deployment, select Deploy from a branch.
5. Select branch main and folder /(root), then Save.
6. Wait for GitHub Pages to publish. The link will look like:
   https://YOUR-USERNAME.github.io/pariii-birthday/
7. Open the link on a phone and test the music button.

The uploaded audio is included in the website folder. Browsers block autoplay until the visitor taps, so the song begins after she taps “Open your surprise” or “Play Dilruba Dilnasheen”.
Only share the site publicly if you have permission to share the photos and audio.
